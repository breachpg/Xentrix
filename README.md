# Xentrix website

Open `index.html` in any browser to view it. Everything (styles, scripts) is in that one file.

Quick edits in VS Code (use Ctrl+F / Cmd+F to find these):
- Hero rotating words: search `const words`
- Hero colours per word: `const hues`
- Concept tiles: search `class="tile`
- Services list: search `class="cap`
- Everyday AI example logs: search `const data=`
- Email address: search `@xentrixltd.co.uk`
- Colours and fonts: the `:root{` block at the top of the <style>

Tip: install the "Live Server" extension in VS Code, right-click index.html and choose "Open with Live Server" to see changes instantly.
